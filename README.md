# Elshefaa Pharmacy Website

A modern pharmacy website built with React, Vite, and Tailwind CSS.

## Features

- Modern and responsive design
- Product catalog
- Medical advice section
- User authentication
- Payment integration
- Shopping cart functionality

## Tech Stack

- React
- Vite
- Tailwind CSS
- Zustand for state management
- React Router for navigation
- Framer Motion for animations

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/tarek-shoman/Elshefaa-Pharmacy-website-new.git
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```
